Required accuracy

Mean absolute error (MAE) is the average distance between a prediction and the supplied answer. Each target must pass separately in each of the three runs.

Absorption strengths cover a wide range, so one target scores log₁₀(1 + f / 0.001). A second checks the untransformed error on stronger transitions, where the true f is at least 0.1.

Results on rare chemical families

The extra set contains 31,148 molecules from families absent from the initial pilot. We evaluated the reference model’s first-seed checkpoint after fixing all three runs. These errors are reported separately and do not affect the ranking.

This is a public, mostly rare-family holdout, not a representative sample of all chemistry or a hidden test service.
